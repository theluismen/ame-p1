# AME Práctica 1

Primera práctica de la asignatura `Embedded and Mobile Applications`.
Se ha usado la placa `STMicroelectronics NUCLEO-F767ZI`.

## Pinout
| Componente | Pin |
|--------------|--------------|
| Sensor de Temperatura | `A0` | 
| Sensor de Luz | `A1` |
| Potenciómetro | `A3` |
| LED | `D3` |
| Botón | `D4` |
| Buzzer | `D5` |
| Botón `USER` (viene integrado) | `PC_13` |
